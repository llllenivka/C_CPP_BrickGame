#  BrickGame (Tetris + Snake)

Учебный проект, объединяющий реализацию классических игр **Tetris (C)** и **Snake (C++)** с акцентом на архитектуру, конечные автоматы и разделение логики и интерфейса.

Проект демонстрирует:
- переход от **структурного программирования (C)** к **ООП (C++)**
- использование **конечных автоматов (FSM)** для игровой логики  
- применение архитектурного паттерна **MVC**
- разработку **кросс-интерфейсного приложения** (CLI + Desktop GUI)

---

##  Реализованные игры

###  Tetris (C, C11)

- Реализован как библиотека + CLI интерфейс (ncurses)
- Логика построена на **конечном автомате**
- Поддержка всех базовых механик:
  - вращение фигур  
  - движение по горизонтали  
  - ускоренное падение  
  - уничтожение линий  
  - отображение следующей фигуры  
- Реализованы:
  - система очков  
  - уровни (ускорение игры)  
  - хранение рекорда  

---

###  Snake (C++, C++20)

- Реализован с использованием **ООП**
- Архитектура: **MVC (Model-View-Controller)**
- Логика также основана на **FSM**
- Поддержка:
  - автоматического движения  
  - роста змейки  
  - столкновений (границы / сама с собой)  
  - победного состояния (максимальная длина)  
- Реализованы:
  - система очков  
  - уровни сложности

---

### 🔁 Конечный автомат (FSM)

Игровая логика реализована через состояния:

- Start  
- Spawn  
- Move  
- Shift  
- Merge / Collision  
- Game Over  

Преимущества:
- предсказуемое поведение игры  
- удобное тестирование  
- расширяемость  

---

###  MVC (в Snake)

- **Model** — игровая логика  
- **View** — GUI / CLI  
- **Controller** — обработка ввода  

Бизнес-логика полностью отделена от интерфейса.
